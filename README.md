##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gratien-iradufasha/portfolio-website.git
```

### 2. Enter the project directory

```bash
cd portfolio-website
```

### 3. Open the website

You can simply open `index.html` in a web browser.

For development, you can also use the **Live Server** extension in Visual Studio Code.

##  Download CV

The portfolio includes a downloadable CV.

The CV is stored inside the `documents` directory:

```text
documents/Gratien_Iradufasha_CV.pdf
```

The **Download CV** button links directly to this file and allows visitors to download the latest version of my CV.
